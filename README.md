# 🏃 Late Runner

**Late Runner** is a simple endless runner game built with **Python** and **Pygame** inspired by the Google Chrome Dinosaur Runner. Jump over obstacles avoid flying enemies and survive as long as possible to achieve the highest score!

## 🎮 Features
- Endless runner gameplay
- Smooth jumping mechanics
- Multiple enemy types
- Increasing challenge over time
- Score tracking
- Pixel-art graphics
- Start and Game Over screens

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/maintenanceguy/Late-Runner.git
```

2. Install Pygame

```bash
pip install pygame
```

3. Run the game

```bash
python main.py
```
